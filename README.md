# react-outside-kit

A lightweight React library for outside interactions and UI dismissal.

`react-outside-kit` provides lightweight hooks for handling common UI interactions such as:

- Clicking outside an element
- Pressing the Escape key
- Pointer leave detection
- Hover state

### Features

- ⚡ Lightweight
- 🌳 Tree-shakeable
- 📦 TypeScript support
- ⚛️ React 18 & 19

## Installation

```bash
npm install react-outside-kit
```

## Hooks
- **useClickOutside** 
- **usePointerLeave** 
- **useHover**
- **useEscapeKey**
